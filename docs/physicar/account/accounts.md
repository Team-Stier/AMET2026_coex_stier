# 계정과 로그인

- 원문: <https://physicar.ai/ko/learn/account/accounts/>
- 확인일: 2026-08-19

PhysiCar 계정은 AI 기능, 크레딧, 클래스룸 소속을 연결한다. 가입에는 이메일,
8자 이상의 비밀번호, 2~30자의 영문·숫자·하이픈·밑줄 사용자 이름이 필요하며,
가입 후 이메일 인증을 수행한다. 대한민국의 최소 가입 연령은 만 14세로 안내된다.
최소 연령 미만 사용자는 교사가 제공한 클래스룸 초대 코드로 참여하는 절차를 따른다.

로그인 시 12자리 클래스룸 초대 코드를 함께 입력하거나 나중에 프로필에서 참여할 수
있다. 프로필에서는 클래스룸 소속, 크레딧, 사용자 이름, 비밀번호를 관리한다.

크레딧은 AI 채팅·실시간 음성과 클라우드 시뮬레이터 실행에 사용된다. 가격과 자동
정지·보관·삭제 기간, 월드 게시 한도는 운영 정책이므로 구현에 고정하지 말고 공식
가격 페이지와 원문에서 최신 값을 다시 확인한다.
