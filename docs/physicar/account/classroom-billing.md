# 클래스룸과 결제 정책

- 원문: <https://physicar.ai/ko/learn/account/classroom-billing/>
- 확인일: 2026-08-19

클래스룸 학생의 AI 채팅, 실시간 음성, 클라우드 시뮬레이터 비용은 학생의 스폰서
한도 안에서 교사의 크레딧에서 차감된다. 학생 개인 크레딧은 클래스룸 활동에 사용하지
않는 것으로 안내된다.

교사는 학생별 기본 스폰서 한도, 개별 한도, 허용할 채팅 모델을 설정할 수 있다.
교사 크레딧이 소진되면 새 AI 사용이 중단되고 실행 중인 학생 시뮬레이터가 자동으로
정지된다. 학생이 자신의 스폰서 한도에 도달한 경우에는 교사가 한도를 올릴 때까지
사용이 제한된다.

교사는 초대를 활성화하거나 비활성화하고, 초대 코드를 재생성하며, 학생을 제거하거나
클래스룸 자체를 중단할 수 있다. 구체적인 금액과 기본 한도는 변경될 수 있으므로 공식
원문을 최종 기준으로 사용한다.
