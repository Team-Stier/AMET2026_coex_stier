# PhysiCar 가이드 로컬 참고문서

- 원문: <https://physicar.ai/ko/learn/>
- 확인일: 2026-08-19

이 디렉터리는 PhysiCar 공식 한국어 가이드의 구조와 핵심 계약을 개발 중 빠르게
확인하기 위한 로컬 참고문서다. 최신 동작과 가격·정책은 각 파일에 연결된 공식
페이지를 최종 기준으로 삼는다.
